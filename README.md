# Machine-Learning-Assignments

Assignments from **CS-E3210 Machine Learning Basic Principles** at Aalto University (Oct 2018), taught by Prof. Alex Jung.

## Notebooks

| File | Topic |
|------|-------|
| 1_Introduction.ipynb | Data exploration, basic statistics |
| 2_Regression.ipynb | Linear/polynomial regression, gradient descent |
| 3_Classification.ipynb | kNN, decision trees, image classification |
| 4_Model-Validation-and-Selection.ipynb | Cross-validation, bias-variance tradeoff |
| 5_Clustering.ipynb | k-Means, GMM, Gaussian mixture models |
| 6_*.ipynb | Advanced topics |

## Setup

`
pip install -r requirements.txt
`

**Note:** Some cells import plotchecker, a course-internal grading library not available on PyPI. Those cells can be skipped outside the Aalto course environment.

## Data

Data files (Data.csv, BTC-USD.csv, ETH-USD.csv, images/, fruits/) are course-provided and not included in this repo. BTC-USD.csv / ETH-USD.csv can be downloaded from Yahoo Finance.
